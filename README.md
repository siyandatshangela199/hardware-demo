# SUNSAND HARDWARE – Hardware Store Website Demonstration

A React-based hardware store website demonstration developed to showcase my frontend development skills, data handling, and ability to build interactive web interfaces for retail businesses.

## Live Deployment

The application is deployed on **Render** and publicly accessible through the link below.

**Live Website:** https://hardware-demo-2j62.onrender.com

## Project Overview

SUNSAND HARDWARE is a website demonstration developed around the needs of a real local hardware business in Sterkspruit, Eastern Cape.

The project explores how a hardware store could establish an online presence by showcasing its products, displaying indicative prices, and making essential business information accessible to potential customers.

The application provides a product catalogue with a search feature, allowing visitors to browse products and find specific items.

This is a portfolio demonstration rather than a completed commercial website. Product listings, prices, contact information, and other business details are illustrative and may differ from actual business information.

## Features

- **Product Catalogue:** Displays hardware products with images, names, and indicative price ranges.
- **Product Search:** Allows visitors to search for products by name.
- **Dynamic Search Results:** Updates the product display as users enter search keywords.
- **Product Information:** Presents product details in organised cards.
- **Business Information:** Displays the business location and opening hours.
- **Contact Information:** Provides phone, WhatsApp, and email details.
- **Responsive Interface:** Presents products in an organised layout for browsing.

## Technical Implementation

- Used React's `useState` hook to manage search input.
- Implemented client-side product filtering using JavaScript's `filter()` method.
- Used `map()` to dynamically render product cards from structured data.
- Implemented conditional rendering for search results and empty states.
- Organised product information using JavaScript objects and arrays.
- Integrated product images and icons into the user interface.
